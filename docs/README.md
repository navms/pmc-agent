# pmc-agent 工程知识沉淀

本文档面向**刚接触 Agent 开发的读者**。不默认你已经知道 ReAct、Tool、HITL、AG-UI 是什么；每篇会先把概念讲清楚，再用本仓库的真实设计说明「为什么这样做」。

| [02-开发问题与方案取舍](./02-开发问题与方案取舍.md) | 2026-09-11 至 09-12：编排演进与第一轮坑 |

## 建议阅读顺序

1. 先读 **01**：建立产品与架构心智模型。遇到不懂的词，文内会先解释。
2. 再读 **02**：理解「为什么不是更简单的写法」。这是面试里最容易被追问的部分。
3. 需要对照 09-12 之后的改动时读 **04**。回测实现细节读 **05**。
4. 最后读 **03**：用问答检验自己是否真懂。每题前有知识点铺垫。

## 材料范围

整理自 2026-09 本仓库开发会话与当前代码。01–03 对应 09-12 下午之前的主线；04 对应其后增量（含 `feat/session-thumbs-down-langfuse` 上的点踩与意图澄清）。更早的 boot-framework / 银医方案会话在本机 transcript 中不完整，文中已标明边界。

当前权威运行栈：**AgentScope Java 2.0.3 + HarnessAgent + AG-UI + Langfuse**。文中会提到曾用过的 Spring AI Alibaba，那是演进过程，不是现网方案。
