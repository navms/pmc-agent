# pmc-agent 工程知识沉淀

本文档面向**刚接触 Agent 开发的读者**。不默认你已经知道 ReAct、Tool、HITL、AG-UI 是什么；每篇会先把概念讲清楚，再用本仓库的真实设计说明「为什么这样做」。

## 读什么

| 文档 | 解决什么问题 |
|---|---|
| [01-当前系统功能](./01-当前系统功能.md) | 这个系统是干什么的？用户点一句话之后，后台发生了什么？ |
| [02-开发问题与方案取舍](./02-开发问题与方案取舍.md) | 开发过程中踩过哪些坑？为什么最终选了现在这套方案？ |
| [03-Agent开发面试题](./03-Agent开发面试题.md) | 国内面试常问什么？怎样用本项目的机制回答，而不是背名词？ |

## 建议阅读顺序

1. 先读 **01**：建立产品与架构心智模型。遇到不懂的词，文内会先解释。
2. 再读 **02**：理解「为什么不是更简单的写法」。这是面试里最容易被追问的部分。
3. 最后读 **03**：用问答检验自己是否真懂。每题前有知识点铺垫。

## 材料范围

整理自 2026-09 本仓库开发会话与当前代码（分支主线：`feat/spring-ai-alibaba-init`）。更早的 boot-framework / 银医方案会话在本机 transcript 中不完整，文中已标明边界。

当前权威运行栈：**AgentScope Java + HarnessAgent + AG-UI**。文中会提到曾用过的 Spring AI Alibaba，那是演进过程，不是现网方案。
